# GrydIn

**AI agents, automation and custom software built around how your business actually runs.**

GrydIn is an Islamabad-based AI engineering company. We build for businesses in Pakistan and worldwide.

Most businesses don't have an execution problem. They have a visibility problem. Work piles up in the gaps between tools, teams and decisions until nobody is watching it. We find those gaps and build what closes them.

## What we build

- **AI agents:** systems that think and act on their own, handling repetitive decisions and workflows end to end
- **Business and process automation:** custom and no-code automation (including GoHighLevel)
- **System integration and API development:** CRMs, ERPs, internal tools and third-party platforms connected into one operation
- **Custom software and SaaS:** full-stack web and mobile products
- **Retail and commerce technology:** e-commerce platforms, real-time replenishment and retail solution

## Products and platforms

- **[Qualifyr](https://github.com/grydin-technologies/qualifyr) (open source):** a buyer-only GTM lead engine for Pakistan and the GCC. It researches companies from open data, rejects vendors and agencies using explainable rules, and uses LLM reasoning to score each lead 0–100 with reasons. It exports outreach-ready CSVs. Free stack, local-first.
- **GrydIn Replenish:** real-time stockroom-to-floor replenishment notifications, so shelves get restocked as soon as they run low.
- **[SevenLeaps](https://sevenleaps.com):** a production AI career marketplace built for a US company. It unifies ingestion and matching with self-expanding discovery, at scale.
- **E-commerce suite:** a full commerce platform with a customer app, picker app, rider app and admin panel. AI-enabled and automated across ordering, fulfilment and delivery.
